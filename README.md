
# 💻 VHDL-Projects

---

Bienvenido a **VHDL-Projects**. El siguiente repositorio cuenta con una colección de diseños digitales realizados en VHDL. Los diseños siguen una progresión de nivel empezando desde lo más básico hasta proyectos más complejos. Todos los diseños son sintetizables y han sido probados mediante la herramienta **Vivado 2017.4**. Cada uno de los diseños cuenta con el código fuente VHDL y su correspondiente test bench.

La idea original viene del repositorio **VHDL-100-Projects** donde se pueden adquirir conocimientos en electrónica digital.
