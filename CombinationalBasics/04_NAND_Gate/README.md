# 🔌 NAND_Gate Design

Implementación VHDL de una puerta lógica NAND de 2 entradas. Incluye el código fuente y el testbench para la simulación y la comprobación del diseño.

## 📂 Ficheros Principales
* **NAND_Gate.vhdl:** Código fuente con la entidad y la arquitectura.
* **NAND_Gate_tb.vhdl:** Testbench para simular el diseño y comprobar su comportamiento.
