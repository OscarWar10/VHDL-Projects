# 🔌 XOR_Gate Design

Implementación VHDL de una puerta lógica XOR de 2 entradas. Incluye el código fuente y el testbench para la simulación y la comprobación del diseño.

## 📂 Ficheros Principales
* **XOR_Gate.vhdl:** Código fuente con la entidad y la arquitectura.
* **XOR_Gate_tb.vhdl:** Testbench para simular el diseño y comprobar su comportamiento.
