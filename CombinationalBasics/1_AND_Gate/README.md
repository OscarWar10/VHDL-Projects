# 🔌 AND_Gate Design

Implementación VHDL de una puerta lógica AND de 2 entradas. Incluye el código fuente y el testbench para la simulación y la comprobación del diseño.

## 📂 Ficheros Principales
* **AND_Gate.vhdl:** Código fuente con la entidad y la arquitectura.
* **AND_Gate_tb.vhdl:** Testbench para simular el diseño y comprobar su comportamiento.

## ⚙️ Simulación y Salidas Esperadas
### 📊 Tabla de Verdad: Puerta Lógica AND

| Entrada A | Entrada B | Salida (A AND B) |
| :---: | :---: | :---: |
| 0 | 0 | **0** |
| 0 | 1 | **0** |
| 1 | 0 | **0** |
