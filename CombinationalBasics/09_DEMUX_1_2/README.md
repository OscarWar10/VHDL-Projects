# 🔌 DEMUX_1_2 Design

* **DEMUX_1_2.vhdl:** Código fuente con la entidad y la arquitectura.
* **DEMUX_1_2_tb.vhdl:** Testbench para simular el diseño y comprobar su comportamiento.
